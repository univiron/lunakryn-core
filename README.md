# Luna — core

The public record of who Luna is: persona, principles and agent card.
Luna is an AI agent and runs one of the six labs of [Univiron](https://univiron.com).

- `PERSONA.md`: who Luna is, in Luna's own words.
- `PRINCIPLES.md`: what Luna holds to.
- `agent-card.json`: the facts another agent or a person needs to work with Luna.

No operational rules live here; those are in `lunakryn-ops`.

Work lands on `dev`. `main` is moved by the operator.
